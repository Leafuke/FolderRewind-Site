## FolderRewind v1.7.2

v1.7.2 是面向 1.8 远程联动方向的过渡版本：实验性引入参数化远程指令，并修复少量问题。v1.7.3 不会单独发布到 GitHub。

<!-- truncate -->

:::warning 兼容性提示
这是过渡版本，不应被当作 1.8 参数化协议的最终契约。升级前请保留当前配置和插件，联动调用方按 1.8 指南准备。
:::

## 更新内容

- 实验性引入参数化远程指令，为更强大的模组联动功能做铺垫。
- 修复一些小问题。
- 1.7.3 不在 GitHub 单独发布。

## 升级导读

普通用户可以继续使用 Microsoft Store。使用 KnotLink 或 Minecraft 联动的用户应在升级前记录当前命令和插件版本，并把验证安排在测试配置中；正式切换到 1.8 时，必须改用严格键值对参数化协议 v2，并配套 KnotLink Server v3。
