官网与文档：https://folderrewind.top/

FolderRewind 1.9.3 是 **1.9 系列的首个公开正式版本**。自 v1.8.2 以来，本次版本累计整合 **307 个提交**，重点重构了历史记录与分支模型、插件系统、游戏存档发现与首次使用流程，并对备份 / 还原、云同步、安装和应用生命周期进行了大量可靠性改进。

**微软应用商店版本更新将在几天后跟进以确保可靠性**。

本版本内置 **MineRewind 1.9.5**；插件开发基线为 **Plugin API 3.6**，`FolderRewind.Plugin.Abstractions` 版本为 **3.6.0**。

## ✨ 更新亮点

### 全新的历史记录、分支与检查点系统

1. **重构历史记录核心**

   - 使用新的不可变历史模型、Commit Pack、Checkpoint、Branch 和 Representation 架构替代旧历史实现。

   - 历史记录现在能够更准确地区分来源、备份批次、分支以及实际可还原状态。

   - 历史索引可从持久数据重新构建，并增强了异常中断后的恢复与修复能力。

2. **更完整的分支工作流**

   - 支持按文件夹来源维护独立分支。

   - 支持创建与管理检查点，并按来源或备份批次浏览历史。

   - 支持 **Quick Restore** 与 **Checkout** 两种不同的恢复工作流。

   - Checkout 前会检查并保护当前未提交状态，降低切换历史状态造成数据丢失的风险。

   - 支持多分支状态收敛以及更明确的工作区历史锚点。

3. **新增分支 Merge**

   - 支持持久化的、保守的**文件级分支合并**。

   - 自动处理能够安全确定结果的文件变更，并为冲突提供显式解决流程。

   - Merge Session、冲突决策和准备结果均可持久化，异常退出后能够恢复。

   - 加强合并前的 Exact Representation 完整性验证、共同祖先查找以及提交后的恢复边界。

   - 支持显式准备 Merge 所需的云端副本，不会在 Apply 阶段静默下载缺失数据。

   - 完善长路径、加密归档、空目录、损坏副本和备用副本等场景的处理。

   - Merge 完成后仍可从合并后的历史节点执行 Exact Restore。

4. **历史记录导入与导出**

   - 支持使用 `.frhistory` 文件迁移历史仓库。

   - 增强历史仓库绑定、修复和传输能力。

从旧版本升级后，建议先查看应用中的**迁移报告**并确认历史和备份状态正常，再清理任何旧数据。

### 💾 备份与还原

1. **更精细的备份范围**

   - 支持精确选择目录、文件和 glob 规则。

   - 支持在已有配置中编辑来源备份范围。

   - 改进来源范围比较、预览和差异检测。

2. **更可靠的备份事务**

   - 配置级备份统一为原子提交模型。

   - 使用不可变 Rolling Copy-on-Write 方式替代部分旧覆盖行为。

   - 阻止来源路径与备份目标发生危险重叠。

   - 加强备份失败、取消、补偿和最终状态处理。

3. **更安全的还原**

   - 重构 Restore 与 Checkout，使其统一基于 Version / Representation 工作。

   - Safe Restore 的暂存阶段能够保留当前目录的完整状态。

   - 新增单次操作的文件 / 目录强保留参数。

   - 改进还原期间的配置协调、身份校验和提交后状态处理。

4. **取消行为更加一致**

   - 修正普通备份、自动备份、云同步和历史云上传中的取消语义与资源释放。

   - 避免取消操作导致错误的成功 / 失败状态或遗留后台任务。

### 🎮 游戏存档发现与首次使用体验

1. **新增游戏存档自动发现流程**

   - 增加统一的 Discovery Provider 架构。

   - 支持基于 **Ludusavi** 规则发现游戏存档。

   - 支持识别 Steam、GOG、Epic 等游戏安装来源。

   - 插件也可以参与游戏发现，并与针对游戏的 Backup Preset 联动。

2. **重新设计发现结果界面**

   - 将“发现 → 检查 → 创建配置”拆分为更清晰的分阶段确认流程。

   - 改善大量结果的阅读空间与层级选择体验。

   - 再次发现游戏时尽可能保留用户已经进行的手工配置修改。

   - 后台扫描、规则校验和哈希计算不会阻塞主要界面操作。

   - 离开发现页面时会及时终止会话并释放扫描资源。

3. **降低大型规则库的资源占用**

   - Ludusavi 清单改为按游戏条目读取，避免重复加载完整规则库。

   - 使用流式方式下载和编译规则。

   - 降低大型索引验证时的内存峰值。

4. **改进入门流程**

   - 新建项目现在采用事务化创建流程，包括配置提交、首次备份以及局部失败后的重试。

   - 增加云连接隔离、云恢复预览和更明确的安全还原流程。

   - 增加 Minecraft 环境诊断。

   - 云存档引导进一步覆盖 rclone / OpenList 使用场景。

   - 设置中增加独立的 OpenList 环境配置，可保存可执行文件路径与服务地址。

   - 新增面向游戏场景的“游戏优先极速”和“极省空间”等性能预设。

### 🧩 Plugin API 3

FolderRewind 1.9 对插件系统进行了大规模重构。

1. **公开 API 与 Host 实现彻底分离**

   - 新增独立的 `FolderRewind.Plugin.Abstractions`。

   - 插件不再需要直接引用 FolderRewind 主程序或 UI 项目。

   - SDK 基于 `net10.0`。

   - FolderRewind 1.9.3 的基线为 **Plugin API 3.6 / Abstractions 3.6.0**。

2. **新的插件 Runtime**

   - 支持事务化 Activation / Deactivation 与安全 draining。

   - 隔离不同插件的私有程序集依赖。

   - 增加类型化设置验证与事务提交。

   - Host 根据插件声明的能力和服务构建受控接口。

   - 插件安装、更新和卸载流程增加更完整的状态管理与恢复能力。

3. **更安全的插件安装与升级**

   - 插件包会先执行 Manifest、版本、文件和静态候选校验，再进入实际 Activation。

   - 更新采用已知良好版本 / 回滚机制，失败时可恢复插件指针、设置、状态和 Runtime。

   - 1.8.2 时代的旧式 flat plugin payload 会进入专门的迁移与 quarantine 流程，避免失败迁移后继续误加载旧 DLL。

4. **扩展插件能力**

   - 配置协调与批量配置创建。

   - Backup / Restore 扩展。

   - History 查询与 Artifact 扩展。

   - 游戏发现定义与 Backup Preset 联动。

   - KnotLink 目标解析、命令元数据和信号能力。

   - 版本元数据捕获。

   - 单次恢复玩家 / 文件保留选项等。

> Plugin API 3 插件仍运行在 FolderRewind 进程内。Host Service 声明用于兼容性检查和用户知情，并不是操作系统级安全沙箱，因此请只安装可信插件。

### ⛏️ 内置 MineRewind 1.9.5

1. 适配 Plugin API 3.6。

2. 增强 Minecraft Java Edition 多启动器存档发现。

3. 增加 Minecraft Bedrock Edition 存档发现。

4. 更好地支持 Minecraft Region / 区域备份范围。

5. 完善玩家数据保留与恢复参数。

6. 改进 KnotLink 当前世界识别、命令协调和能力发现。

7. 改进普通文件夹与 Minecraft 世界之间的元数据识别边界。

8. FolderRewind 发行版中捆绑的 MineRewind 包与最终公开发布的 MineRewind 1.9.5 包保持一致，并校验其 SHA-256。

### ☁️ 云同步

1. 历史云同步重构为 Replica / Artifact / Commit Pack 模型。

2. 支持 Commit Pack 集合并集同步和历史分叉检测。

3. Merge 可以显式准备所需的远程历史副本。

4. 加强上传取消、重试和资源释放逻辑。

5. 改进云端历史与本地历史之间的状态一致性。

### 🖥️ 界面、性能与可靠性

- 修复并统一异步配置保存、失败回滚和后台状态写入。

- 限制页面缓存并修复重复激活造成的生命周期问题。

- 修复日志重复追加，并改进大型日志的增量裁剪。

- 改进历史页面工具栏、Merge 状态、错误诊断和操作反馈。

- 改进高 DPI / 不同窗口尺寸下的 Merge 对话框布局。

- 修复主题默认值和标题栏主题同步。

- 改善高对比度模式、自动化标识和辅助功能标签。

- 移除多处硬编码字符串，并补齐中英文翻译及区域化日期显示。

- 改进系统托盘恢复窗口以及前台激活行为。

- 所有发行形式统一限制为单实例；再次启动时会唤回已有窗口。

- 修复任务栏重启后的图标、快捷方式以及安装器 Shell 身份。

- 大型元数据改为流式、原子读写，减少不必要的历史重新加载。

- 多项扫描、历史查询和后台操作改为真正可取消的异步流程。

一般 Intel / AMD Windows 设备请选择：

- `FolderRewind_1.9.3.0_Setup_x64.exe`

- SHA-256：`e4ba61f81157d098c61bdb2aa2423576d5de5a6e51f72480e4f200823996585f`

Windows on ARM 设备请选择：

- `FolderRewind_1.9.3.0_Setup_arm64.exe`

- SHA-256：`93b92026d101a6e47340c0f9198aac5908ca270aff86f3d27f4be17d707258e9`

Release 同时提供对应的 `.sha256` 文件用于校验安装包。

Setup 提供中英文界面、安装范围和维护选项。卸载时默认**保留用户设置和备份数据**；可以显式选择清理当前用户设置，备份数据仍不会作为普通卸载内容删除。

由于旧版本的更新逻辑可能无法识别新的 Setup 资产格式，如应用内未正确提供 1.9.3 更新，请直接从本 Release 页面下载安装。
