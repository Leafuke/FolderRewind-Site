## FolderRewind v1.8.0

这是一次重要更新，采用全新的远程指令模式，并进行了多项底层改进。

<!-- truncate -->

:::tip 下载建议
Microsoft Store 仍是首选渠道。普通侧载用户可选择 MSI；高级侧载使用 MSIX 7z 包并运行 install.ps1。三种渠道不要并存。
:::

## 更新内容

1. 增加区域备份模式支持。
2. 增加文件夹重命名支持。
3. 增加性能预设功能。
4. 支持 KnotLink v3 服务端和 SDK。
5. 增加多项远程指令。
6. 移除多项向前兼容代码。
7. 适配 Windows App SDK 2.3.1。
8. 修复自动化设置保存错误（[#41](https://github.com/Leafuke/FolderRewind/issues/41) [@LYarHlXS](https://github.com/LYarHlXS)）。
9. 优化页面加载、软件启动和过滤器性能。
10. 使用更严格的区域备份还原策略。

## 远程协议与兼容性

FolderRewind 1.8 要求 KnotLink Server v3，并使用严格键值对的参数化协议 v2；旧的空格分隔指令不再受支持。插件开发者应使用当前参数化接口，并将新接口示例的 MinHostVersion 设为 1.8.0。

## 我要下载哪个？

- **Microsoft Store**：首选，安装和更新最省心。
- **MSI**：普通侧载用户使用，仍属测试中的实验格式；无需开发者模式，但应校验 .sha256。
- **MSIX 7z**：高级侧载，解压后运行 install.ps1，体验最接近 Store。

一般用户下载带 x64 的文件；只有 Windows on ARM 设备选择 ARM64。Store、MSI、MSIX 不应并存，切换渠道前请备份配置、历史和插件。

## 升级导读

从 1.7.4 升级前先在测试数据验证区域备份、重命名和性能预设。更早版本应按顺序迁移到稳定版本后再进入 1.8。遇到启动问题请遵循 [1.8 升级与恢复](/docs/getting-started/v1-8-upgrade)，不要删除整个配置文件。
