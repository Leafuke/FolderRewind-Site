FolderRewind **{{VERSION}}** is available, with easier version comparisons, merging and cloud recovery, plus quieter background tasks.

{/* truncate */}

- **A dedicated merge workspace.** Read text differences, choose file results or import your own edits in the [merge workspace](/docs/guides/history-branches). Review before applying, or return to a saved session later.
- **History on the map.** [Minecraft maps](/docs/guides/minecraft/world-preview) gain historical previews, version comparisons, cave views and height slices. [World merging](/docs/guides/minecraft/world-merge) offers Conservative and Terrain first policies.
- **A clearer path to cloud copies.** Connection, authorization and OpenList workflows have been refined, with a separate [cloud recovery workflow](/docs/guides/cloud-recovery) for a new local folder.
- **Quieter background work.** The [notification center](/docs/guides/notifications) brings results, tasks and logs together. Successful automatic tasks and no-change runs stay quiet.
- **Smoother everyday use.** Backup and restore do less repeated work. [Filters](/docs/guides/filters) can target files, folders or both, alongside improvements to settings and navigation.

This release bundles MineRewind **1.10.0**. Public plugin development uses **SDK 3.17.0**.
