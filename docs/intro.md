# 快速开始

FolderRewind 为 Windows 上的重要文件夹保存版本。工作前留一个备份，误改文件时找回旧内容，也可以让它在后台定期保存项目和游戏存档。

![按项目整理文件夹，从常用来源快速执行备份。](/img/docs/v1-9-6/home-zh-light-1604.webp)

## 从一个文件夹开始

1. [安装应用](/docs/getting-started/installation)，选择 Microsoft Store 或适合设备架构的 Setup 安装包。
2. [创建首次备份](/docs/getting-started/first-backup)，添加文件夹并选择备份位置，保存第一个完整版本。
3. [完成一次还原](/docs/getting-started/first-restore)，用几个测试文件熟悉找回内容的过程。
