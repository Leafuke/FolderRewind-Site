# 快速开始

FolderRewind 为 Windows 上的重要文件夹保留备份版本。你可以随时保存项目进度、安排自动备份，或从历史中找回误改、误删的文件。

![按项目整理文件夹，并从收藏项快速执行备份。](/img/docs/v1-9-6/home-zh-light-1604.webp)

*按项目整理文件夹，并从收藏项快速执行备份。 界面版本：1.9.6。*

## 从一个文件夹开始

1. [安装应用](/docs/getting-started/installation)：优先选择 Microsoft Store，也可下载适合设备架构的 Setup EXE。
2. [创建首次备份](/docs/getting-started/first-backup)：添加文件夹，选择独立备份位置，保存第一个完整版本。
3. [完成一次还原](/docs/getting-started/first-restore)：用测试文件验证结果，再开启自动备份。

## 当前版本

本栏目按 **FolderRewind 1.9.6** 核对。应用内置 **MineRewind 1.9.8**，支持 **Plugin API 3.9**；独立公开插件仍为 **1.9.5**，NuGet 开发示例使用 **SDK 3.6.0**。商店与 GitHub 的更新进度可能不同，请在应用“关于”中查看已安装版本。

[MineBackup 一代教程](/docs/guides/minebackup-v1/overview)描述独立产品，其配置、CLI 和备份模式应按该栏目使用。
