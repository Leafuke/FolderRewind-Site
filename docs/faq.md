# 常见问题

## 应该下载哪个安装包？

优先使用 Microsoft Store。GitHub 提供 x64 和 ARM64 Setup EXE 及同名校验文件：Intel／AMD 电脑选择 x64，Windows on ARM 选择 ARM64。见[安装指南](/docs/getting-started/installation)。

## 如何查看当前版本和更新内容？

在应用“关于”中查看已安装版本，[下载页](/download)介绍当前发行包，[更新日志](/blog)记录各次发布。

## 自动备份完成后，为什么没有弹出提醒？

自动备份和自动云同步正常完成或没有变化时保持安静。点击铃铛查看结果；重要警告和错误按提醒设置通知。见[通知中心](/docs/guides/notifications)。

## 重启后去哪里找之前的任务结果？

通知中心保留本次运行最近 200 条结果。更早的操作可查日志文件，已创建版本可查历史记录。

## Full、Smart 和 Rolling 怎么选？

首次或重要节点选 Full；变化较少且频繁保存时可选 Smart；希望复用可信基线生成独立新归档时可选 Rolling。见[备份模式](/docs/guides/backup-modes)。

## 保留数量设为 N，为什么还有更多版本？

数量按每个来源最近 N 个可恢复版本计算，受保护版本额外保留，0 表示无限。打开手动清理报告，可查看依赖重建和空间变化。

## 快速还原会选哪个版本？

使用活动分支的唯一尖端版本；尚无活动分支时，可以选择最近可恢复的旧备份。恢复更早的状态，请在历史中指定版本。

## 怎样删除旧备份并保留后续版本？

从应用历史页操作，先查看删除影响。应用会按需要重建增量依赖，保留后续版本的恢复能力。

## 云端有历史，恢复还需要准备什么？

选定版本还需要实际归档及其完整依赖。使用[从云端恢复](/docs/guides/cloud-recovery)读取历史、下载和校验数据，再恢复到新的本地目录。

## 怎样过滤整个缓存文件夹？

添加文件夹规则，例如 `cache`。规则会作用于匹配目录及全部子项；保存前在有效文件预览中检查。见[过滤规则](/docs/guides/filters)。

## Minecraft 地图可以查看旧备份吗？

可以。启用 MineRewind，选择可在本地准备的 Java 世界版本，即可浏览历史地图并比较两个版本。见[地图预览](/docs/guides/minecraft/world-preview)。

## 如何合并两个 Minecraft 分支？

在合并工作页为本次会话选择 Minecraft 语义合并，再选保守策略或地形优先，处理区块冲突并审阅结果。见[世界合并](/docs/guides/minecraft/world-merge)。

## 换电脑时要复制哪些资料？

分别准备配置、`.frhistory` 历史和实际归档或云副本，并记录加密密码。按[数据迁移](/docs/guides/data-migration)确认路径和还原结果。

## 插件已启用，如何检查功能状态？

在插件管理中查看实际运行状态、设置和诊断。需要重启时按提示完成；再检查对应来源的项目类型。见[插件管理](/docs/plugins/using-plugins)。

## 遇到“需要恢复”提示怎么办？

保留日志和原始文件，打开应用的受控恢复入口，按诊断完成剩余步骤。恢复完成后再继续相关备份或还原。
