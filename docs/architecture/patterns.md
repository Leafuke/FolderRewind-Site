# 架构模式与事务边界

> 本页描述 1.10 开发分支的重构布局，尚未表示正式版已发布。

界面继续使用 MVVM。ViewModel 管理呈现状态与异步命令，视图代码桥接界面事件；耗时 I/O、事务和恢复放在对应服务中。

Core 保留领域与算法，Host 在组合入口提供依赖。仅在真实边界处引入接口或回调，不增加全局服务定位器。日志与诊断通过显式回调交回 Host；已有操作级诊断上下文仍记录测量和计数。

普通测试引用正式 Core，Core 不再被测试项目作为源文件重新编译。仍需链接的 Host 呈现或适配源码有明确清单；已迁入 Core 的类型不得再次链接。故障注入测试和进程探针使用独立输出，不能污染普通构建。

文件移动与行为变更分开审查。保持现有锁顺序、取消行为、资源释放、序列化字段和版本兼容；结构整理不构成改变这些语义的理由。
