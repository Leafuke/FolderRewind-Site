# 插件安装与管理

在设置中打开插件管理，可以查看已有插件、调整设置，或安装新的扩展。MineRewind 随应用提供，其他插件可按需要添加。

## 从官方目录安装

打开插件商店，选择插件并检查功能、作者、版本、兼容 API 和请求的服务。确认安装后，打开启用开关并查看运行状态。新安装默认停用，启用时才执行插件代码。

## 安装本地文件

从可信作者下载 `.frplugin` 及同名 SHA-256 文件，核对校验值，再使用“本地安装”。应用会检查包结构、声明、设置和入口程序集。

当前包采用根清单结构，包含 `manifest.json`、设置模式和入口 DLL。早期 v2 插件需要作者提供兼容包，迁移说明见[旧插件迁移](/docs/plugins/developing/migration-v2-v3)。

## 设置与运行状态

选择插件进入设置，修改后保存。检查实际状态和诊断，确认依赖服务已准备好。需要重启时按 `RequiresRestart` 提示完成；Safe Mode 会保留启用选择，并暂时停止插件执行。

插件代码使用当前用户权限，安装时请结合来源和服务声明选择可信扩展。

## 更新与回滚

官方更新依据 Catalog 中固定的版本、下载地址、SHA-256 和能力声明。更新前先完成受影响任务，再通过管理页安装新版。应用维护当前与上一份已知良好载荷，出现问题时可按界面执行回滚。

手动分发的包在来源中记录为 Manual，后续维护继续使用作者提供的包和管理入口。回滚前检查新旧插件对已有设置和备份格式的兼容说明。

## 卸载

打开卸载预览，检查代码、设置和可选私有数据的处理范围。已有备份与历史保留在应用中；使用插件专属格式的版本，在恢复时仍需要相应物化能力。

卸载中断后，重新启动应用完成恢复。功能未出现时，依次检查运行状态、API、架构、设置、所需服务和来源类型；相关错误可从插件诊断与日志查看。
