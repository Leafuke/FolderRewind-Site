# 支持 FolderRewind

FolderRewind 是免费开源的备份工具。Microsoft Store 的赞助版是可选的持久附加产品，只解锁外观与提示音选项：主题强调色、Mica/Acrylic 窗口材质、自定义标题及图标、背景图片，以及备份/还原完成音效。备份、还原、历史、自动化、插件和模板功能继续免费使用。

通过 Microsoft Store 购买并由本地许可检查解锁。维护者可能向源码贡献者、提供有价值反馈者和第三方赞助者赠送兑换码；兑换通过 Microsoft Store 或 Microsoft 账户进行，应用不收集兑换码。初次购买、兑换及账户同步需要联网，离线识别取决于已有本地许可缓存。

开源客户端的赞助版不是严格 DRM 边界。应用不主动记录订单、Microsoft 账户、兑换码等私人购买信息。购买和退款由商店政策处理。如已购买但未识别，请确认商店登录账户，重新启动应用，并在设置中刷新购买状态；反馈问题时提供应用及系统版本，不公开订单详情。
