# 模板与备份预设

模板适合复用一套已经顺手的备份策略。压缩、过滤、自动化与保留设置可以一起带入新项目，再根据实际目录调整。

## 保存并使用模板

在项目设置中保存为模板，填写名称、作者和说明。创建项目时选择模板，添加实际来源和备份位置，查看范围与策略摘要后保存。

模板使用 Backup Preset V2 表达策略，并支持导入已有旧格式。游戏定向预设可以引用发现提供器的 DefinitionId，帮助选择相应备份集合。

## 管理与检查

从设置的模板管理中查看、编辑、复制、删除和预览路径规则。使用前检查来源范围、Kind、过滤、保留数量和所需插件；缺少依赖时按创建向导的诊断准备。

Minecraft 增强体验预设可检查并复用 KnotLink Service，按确认流程准备缺少的组件，再检查连接与实际联动。

公开复用方式见[模板分享](/docs/guides/template-sharing)，发现流程见[游戏发现](/docs/guides/game-discovery)。
