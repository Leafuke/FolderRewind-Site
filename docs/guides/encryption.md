# 加密备份与密码保管

加密适合存放在外部磁盘或云端的备份。创建加密项目后，先备份并测试还原一次，再用于重要资料。

## 创建加密项目

在创建流程中选择加密项目并设置密码，检查来源与备份位置。项目密码创建后固定使用，请在可靠位置单独保管。

## 本机使用与迁移

应用通过当前 Windows 用户范围的 DPAPI 保护本机密码材料，同机同用户可使用保存的材料。迁移到另一设备或用户前，另行准备原加密密码，复制完整归档和增量依赖。

配置导出保存项目设置；加密密码按自己的密码管理方式保管。忘记密码后，需要找回原密码才能解密内容。

## 还原与检查

按界面输入密码，应用解包并验证内容后修改目标。先在测试目录核对文件，确认密码与归档完整，再启用自动化或云上传。

插件物化可能读取解密内容，按来源与功能选择可信插件。遇到失败时，分别检查密码、归档位置和依赖链，保留原始副本并查看操作日志。
