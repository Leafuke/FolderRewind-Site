# 加密备份与恢复材料

## 创建

在新建流程选择加密项目／按界面设置密码，确认测试来源与目标，完成第一份备份。密码创建后不能直接修改；妥善记录，不把密码写进模板或日志。

## 密码与设备

Host通过当前用户范围Windows DPAPI保护本地密码材料，不明文写配置JSON。同机同用户解密能力不等于跨设备可移植；仅导入config.json不足以恢复密码存储。提前保存必要密码并在新设备副本验证恢复。

## 还原

按Host界面完成密码验证后物化目标表示；错误密码／完整性失败拒绝，不先修改live来源。Full／Smart／Rolling的载荷依赖仍需完整。插件ArtifactRead／materializer可能读取解密内容，启用前核对声明和信任。

## 验收与建议

验证正确密码、错误密码、跨设备、缺失依赖、取消和真实还原内容。加密保护存储内容，不提供密码找回，也不替代Safe Restore／备份副本／范围核验。
