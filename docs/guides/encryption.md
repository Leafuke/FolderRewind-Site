# 加密备份与恢复材料

加密适合保护存放在外部磁盘或云端的归档内容。设置密码后，先完成一次加密备份和测试还原，再用于重要资料。

## 创建加密项目

按创建流程选择加密项目并设置密码，检查来源与备份位置。密码创建后不能直接修改；在可靠位置单独保管，不放入模板、备注或日志。

## 本机密码与跨设备恢复

应用使用当前 Windows 用户范围的 DPAPI 保护本地密码材料，不以明文写入配置 JSON。同机同用户可以使用这些材料，换电脑或换用户则不能假定可以直接解密。

导出配置不等于导出密码存储。迁移前记录加密密码，在新设备的归档副本上验证还原；忘记密码时应用不提供找回功能。

## 执行还原

根据界面输入或确认密码。应用先解包和验证，再修改目标；错误密码或完整性失败会拒绝执行。Smart 等模式仍需要完整的归档依赖。

插件的归档读取或物化能力可能接触解密后的内容，只启用可信插件。加密保护归档内容，仍需检查备份范围并保留可靠副本。

## 遇到问题时

核对密码、来源归档和依赖链。跨设备失败时，先区分密码材料不可移植和归档缺失；不要仅通过反复导入配置尝试修复。保留原归档，避免覆盖唯一副本。
