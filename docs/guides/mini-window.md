# Mini 悬浮窗

## 打开与操作

从来源行菜单打开Mini；已有窗口再次打开会激活。窗口绑定稳定来源，用于监控变更、备份和备注，任务仍由Host执行，关闭Mini停止该窗口监控，不删除历史。

新版提供紧凑／展开状态、Acrylic外观、任务反馈、多屏边界与DPI适配；这些界面细节以实际版本为准。状态文本不应仅用颜色解释。

## 快捷键

默认Ctrl+Alt+A操作最近激活Mini窗口的来源，可在快捷键设置中修改。先确认窗口、绑定来源、焦点与系统冲突；它与MineRewind当前世界Alt+Ctrl+S／Z不同。

## 验证

测试多窗口切换、连续无变更、任务进度／取消、备注、多屏与高DPI，以及关闭再开。选择Smart或Rolling仍需独立还原验证；不要把轻量窗口成功动画当数据一致性证明。
