# Mini 悬浮窗

悬浮窗让你在工作或游戏旁边查看文件夹变化、填写备注和执行备份，适合不想一直展开主窗口的场景。

## 打开与备份

在管理页打开来源的操作菜单，选择 Mini 窗口。已有窗口会被唤回；每个窗口绑定对应来源。可以切换紧凑和展开状态，查看任务反馈并触发备份。

关闭悬浮窗会停止该窗口的监控，不删除历史。实际任务仍由应用执行，结果可在任务与历史页面查看。

## 使用快捷键

默认 `Ctrl+Alt+A` 操作最近激活的 Mini 窗口来源，可在快捷键设置中修改。多个窗口同时打开时，先激活需要的窗口；该快捷键与 MineRewind 当前世界的 `Alt+Ctrl+S`、`Alt+Ctrl+Z` 不同。

## 检查结果

关注来源、备注和任务终态。切换 Smart 或 Rolling 后仍需验证还原。热键无响应时，检查最近激活窗口、按键冲突和来源状态；多屏移动后确认窗口仍在屏幕可见范围内。
