# 安全快照与恢复点

分支切换或合并前，安全快照可以为当前工作保留一个精确恢复点。快照独立于活动分支保存，方便需要时找回操作前的状态。

## 操作前保护

在 Checkout、Merge 或相应受控还原的确认界面检查当前工作与保护选项。等待保护捕获完成，再继续写入。打开高级历史中的恢复点入口，可以查看涉及的来源和检查点。

## 恢复与释放

选择恢复点，核对来源路径，准备归档及全部依赖，再通过应用执行恢复。保留快照也会保留其物化依赖，因此实际数量可能高于日常保留数量。

确认后续版本与备份已妥善保存后，可以显式释放恢复点。应用会继续结合其他保护与依赖计算物理清理。

## 遇到问题

出现归档缺失、文件占用或需要恢复的结果时，先查看诊断并完成对应处理。建议先在小项目中试一次创建、重启后查看、恢复与释放。

旧版接管后范围受限的备份，可先恢复到新目录并创建新的 Full 基线，再用于分支操作，见[旧备份接管](/docs/guides/data-migration#legacy-upgrade)。
