# 通知中心与任务结果

备份在后台运行时，你可以照常工作。需要查看结果时，点击窗口里的铃铛，打开通知中心。

![通知中心汇总任务结果，并提供详情、任务和日志入口。](/img/docs/v1-10-0/notifications-110-zh-light-1604.webp)

## 查看一次操作的结果

通知会显示操作名称、关联项目与结果。选择一条记录展开详情，可以打开相关位置，或查看这次操作的日志。批量备份会汇总新备份、无变化、警告和失败的数量，方便找到需要处理的来源。

自动备份和自动云同步正常完成或没有变化时，结果会留在中心，提醒保持安静。遇到重要警告、错误或需要恢复处理的情况，应用会按提醒设置通知你。

## 整理通知

- 用“全部”和“未读”筛选记录；铃铛角标统计未读的重要结果和错误。
- 阅读详情后可标记已读，也可以选择“全部已读”。
- 清除已读结果后，10 秒内可以撤销。

中心保留本次运行最近 200 条结果。重启后，需要查找更早的操作时，请打开日志文件；备份版本继续保存在[历史记录](/docs/guides/history-timeline)中。

## 选择提醒方式

在设置的通知区域调整提醒开关、系统通知级别和完成提示音。窗口在前台时可直接查看应用内结果，在后台时按所选级别接收系统提醒。

从通知跳转到任务或日志后，页面可能只显示该次操作的内容。选择“显示全部任务”或“显示全部日志”，即可回到完整列表。

## 处理警告或失败

先打开详情，确认具体来源和完成阶段。例如，本地备份已完成、云上传失败时，可以保留本地版本并重试上传。需要恢复处理的结果会说明下一步，请按诊断完成恢复后再继续相关操作。

继续阅读[自动化备份](/docs/guides/automation)和[云存档](/docs/guides/cloud-archive)。
