# 管理文件夹与历史绑定

在管理页选择备份项目，添加来源、查看状态和执行备份。每个来源有稳定身份，用于连接当前目录与已有历史。

![管理页中的演示来源与操作入口。](/img/docs/v1-9-6/manager-zh-light-1604.webp)

*管理页中的演示来源与操作入口。 界面版本：1.9.6。*

## 添加与整理来源

使用“添加文件夹”选择单目录、子目录或插件发现结果。检查来源与归档位置没有重叠，填写便于识别的名称和说明；收藏后可从首页快速访问。

编辑来源范围时，选择全部内容或相对包含规则，查看有效文件预览。显示名称和路径可以变化，但不能用另一个同名文件夹代替原来源身份。

## 重命名

打开来源的操作菜单选择重命名，检查源目录、备份目录、元数据和配置引用的变化预览。处理同名冲突后再确认。

失败时应用会尝试回滚；若回滚失败，先确认路径与配置是否一致，再继续备份还原。已有云对象和不可变历史不会随本地显示名全部物理改名，不要在资源管理器中批量改归档名称。

## 绑定旧历史来源

还原或切换历史状态时，旧来源可能缺少当前路径。按界面确认实际位置，并保留原稳定来源身份建立绑定。恢复到另一个目录只是导出文件，与补回历史来源绑定不同。

## 保存后检查

等待保存结果，检查目录、范围、自动化目标和旧版本可还原状态。配置保存失败会回滚，修复权限或磁盘问题后重新保存；尚未落盘的输入不代表已生效。

Minecraft Java 来源可从操作菜单打开[地图预览](/docs/guides/minecraft/world-preview)，普通资料可使用[悬浮窗](/docs/guides/mini-window)辅助日常备份。
