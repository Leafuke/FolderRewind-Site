# 查看历史与管理版本

历史页把一个文件夹的保存进度放在一起。选择项目和来源，就可以找版本、添加备注、查看分支或开始还原。

![按来源浏览活动分支与可还原版本。](/img/docs/v1-9-6/history-zh-light-1604.webp)

## 查找版本

普通视图适合筛选、备注、保护与还原。可以按来源浏览版本，也可以按备份批次查看参与来源的结果。一次无变化运行可以沿用已有版本。

高级视图展示来源分支、Checkout 与 Merge。先看活动分支，再选择对应版本；每个来源分别保留分支和检查点。

## 准备还原

选择版本，查看范围、可还原状态和归档诊断。准备本地归档或可信云副本及完整依赖，再核对目标路径和保护选项。Clean 恢复受管范围内的状态，Overwrite 保留未覆盖内容。

Java 世界还可以打开[历史地图和版本对比](/docs/guides/minecraft/world-preview)。从云端找回独立目录，见[云恢复](/docs/guides/cloud-recovery)。

## 快速还原

快速还原使用活动分支的唯一尖端版本；尚无活动分支时，可选择最近可恢复的旧备份。当前状态已精确匹配时返回 `NoChanges`。需要更早状态时，直接手选版本。

## 保护与清理

将重要版本标记为受保护，可以在数量清理之外保留。数量按每个来源最近 N 个可恢复版本计算，见[保留策略](/docs/guides/backup-modes)。

删除前阅读影响预览。应用会按需重建增量依赖，保留后续版本，并显示进度和空间变化。重建需要临时空间，中断后按恢复提示完成清理。

界面隐藏、释放本地归档和云副本退役各有确认内容，按需要选择。缺失归档时，可以先查云副本和旧备份接管报告，再决定维护方式。

## 分支与当前文件

尝试不同方案时使用[分支切换与合并](/docs/guides/history-branches)。普通还原还可以选择[当前文件保留](/docs/guides/filters#restore-preserve-paths)，并从[通知中心](/docs/guides/notifications)查看操作结果。
