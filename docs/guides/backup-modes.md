# Full、Smart 与 Rolling 备份

## 模式比较

| 模式 | 当前行为 | 建议 |
|---|---|---|
| Full | 为有效受管边界创建独立完整捕获 | 首次备份、里程碑与重新验证 |
| Smart | 基于基线记录增删改与依赖表示 | 高频保护并定期验证依赖闭包 |
| Rolling | 从可信基线写时复制生成不可变新归档，精确反映增删改 | 重用基线处理但保留版本历史 |

Rolling **不更新最近的旧包**，旧包保持不变；基线无法验证时回退 Full。配置旧数值 Incremental=1 对应 Smart，Overwrite=2 对应 Rolling。还原模式 Overwrite 是另一概念，仍用于覆盖恢复。

## 设置与成本

在配置设置的备份策略选择模式，核对来源范围、压缩格式和目标目录。Full 对源范围内状态完整，不表示整个物理磁盘／根目录都受保护。Smart 的基线缓存可重建，丢失缓存可能触发 Full；删除依赖则可能影响还原。

无变更跳过、KeepCount、Smart 链长上限和性能预设以保存的配置为准。链长上限默认5，达到阈值产生新的 Full 基线；旧链是否释放由保留策略与保护根共同决定。

## 保留与删除

保留数量围绕配置 Checkpoint，不再简单按每个文件夹压缩包计数。Pins、分支尖端、Workspace 基线、安全恢复点和活动操作可能使实际保留量高于数量。逻辑历史、表示释放和物理副本删除不同；使用应用内操作，不手工删除依赖。

## 压缩与性能

压缩等级／线程数／低优先级和文件类型规则影响归档成本。0线程表示自动；轻量限制约半数逻辑处理器，极轻量最多2。文件类型压缩规则会禁用 solid。高级7-Zip参数只用于备份创建；操作、格式、密码、输出、来源及进度控制开关受 Host 限制。

## 部分捕获

区域或一次性缩小范围产生部分捕获时，普通和热还原强制 Overwrite。即使 Representation 有 Exact fidelity，也不能清空未备份内容。固定 Source Scope 定义受管边界，不能把边界内的完整捕获与整物理目录混淆。

用测试文件验证新增、修改、删除、缺失基线及还原；不要仅比较压缩包大小。
