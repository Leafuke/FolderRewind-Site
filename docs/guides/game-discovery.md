# 自动发现游戏存档 Beta

游戏发现可以帮你找到常见游戏的存档，再按需要选择保护哪些内容。打开页面后，先准备清单，再开始扫描。

## 准备与扫描

选择下载或更新 Ludusavi 清单，也可以使用已保存的有效清单与本地覆盖。Windows Beta 从 Steam、GOG 和 Epic 的安装信息定位游戏，结合资源规则寻找存档。

选择商店、账号与扫描位置，开始后查看逐根诊断。Steam 默认选最近账号，其他账号可以展开检查。注册表类资源会显示支持状态，当前备份以文件资源为主。

## 审阅并创建项目

1. 先选择游戏与备份集合，再检查每个来源和资源。
2. 核对账号、完整路径和包含范围，选择适合的备份预设。
3. 填写项目名与备份位置，检查最终摘要后创建。

每个来源可以保护整个目录或指定的相对 Include 范围。项目过滤和插件策略在该范围内继续筛选。保存前使用有效文件预览确认最终内容。

## 再次发现

重新扫描时，应用比较上次审阅结果、当前配置和新候选，默认保留手工修改。路径移动、上游新增或范围收缩等变化会集中供你审阅，再保存到项目。

## Minecraft 与自定义位置

Minecraft 创建入口可以直接自动发现，结合已知启动器位置和记住的根目录。便携启动器或自定义世界可手选扫描，按草稿实际 Java／Bedrock 类型确认，见[Minecraft 快速开始](/docs/guides/minecraft/quick-start)。

项目创建后，先完成一次备份和测试还原，再安排[自动化](/docs/guides/automation)。
