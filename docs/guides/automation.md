# 自动化备份任务

熟悉手动备份和还原后，可以让 FolderRewind 在应用运行期间定期保存。打开项目设置的“自动化”，选择触发方式和要保护的来源。

![在自动化设置中选择触发方式与备份目标。](/img/docs/v1-9-6/automation-zh-light-1604.webp)

## 选择触发方式

| 方式 | 使用场景 | 设置内容 |
| --- | --- | --- |
| 间隔 | 工作期间持续保存 | 间隔分钟数、选定来源 |
| 计划 | 固定时间保存 | 月、日、时、分；月或日为 0 表示每月或每天 |
| 启动时 | 打开应用后保存一次 | 项目开关、启动后的来源状态 |
| 文件解锁 | 程序结束占用后备份 | 来源内相对文件路径、锁定到释放的过程 |

文件解锁响应从占用到解除占用的变化。Minecraft 可使用 `session.lock`；先运行一次游戏并退出，观察实际触发结果。

## 保存并观察一次运行

检查来源选择后保存设置。打开任务页确认触发时间和处理结果，也可以点击[通知中心](/docs/guides/notifications)查看汇总。

自动备份正常完成或没有变化时保持安静。重要警告和错误按通知设置提醒。“无变化时跳过”会省下重复归档；连续无变化达到设置阈值时，可自动停止任务，有变化后计数重新开始。

## 配合保留数量与云上传

在资源设置中选择每个来源的保留数量，重要版本可以额外保护。具体规则见[备份模式与保留数量](/docs/guides/backup-modes)。

测试过云连接和恢复后，启用备份后自动上传。本地备份、归档上传与历史同步分别显示结果；某个云阶段失败时，可保留本地版本并重试对应阶段。

## 暂停、取消与排查

需要停止后续触发时，关闭自动化或停止对应任务。正在执行的备份从任务入口取消，等待清理完成后再操作同一项目。创建向导启动的首次备份也可以在全局任务中查看和取消。

没有按时触发时，依次检查应用运行状态、自动化开关、来源选择和时间计划。Minecraft 等插件来源还需检查插件状态与一致性要求；打开任务诊断可查看本次采用的来源和等待条件。
