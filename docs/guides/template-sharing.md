# 模板分享、导入与官方预设

导出和分享可复用备份策略，检查模板格式、插件依赖与个人路径，再导入新项目。

## 本地导入导出

在设置的模板数据区域选择模板导出，保存其分享文件；导入先验证格式和模式，再处理覆盖／保留两份冲突。1.9 有 V2 策略及旧格式兼容，不手工删 envelope 或版本字段绕过校验。

## 官方索引与分享码

浏览官方模板或输入分享码，核对来源、内容、依赖插件和适用游戏；官方双轨索引合并兼容预设，实际定义仍由指定 provider 解析。下载源／镜像影响访问，不改变 Kind 或信任声明。

## 提交分享

应用可准备分享包并通过 GitHub 提交工作流获得 PR／分享码。先检查路径、Provider State、密码／令牌和过滤边界；登录与提交是独立操作，预览不代表已公开发布。

在独立测试环境验证另一电脑的路径命中、插件依赖、创建草稿和备份／还原。模板不携带历史仓库和载荷，不应将分享模板当跨设备数据恢复。
