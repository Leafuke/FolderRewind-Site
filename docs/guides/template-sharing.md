# 模板分享与官方预设

把模板分享给朋友，可以一起复用压缩、过滤和自动化策略。分享前先检查它在另一组目录上的表现。

## 本地导出与导入

从设置的模板数据区域选择导出，保存分享文件。导入时应用验证格式，并在名称等冲突时提供覆盖或保留两份的选项。保留应用生成的版本与格式字段，方便后续检查。

## 官方预设与分享码

打开官方模板列表或输入分享码，检查说明、作者、适用游戏、路径规则和插件依赖。下载后结合实际发现结果或手选目录创建项目。

## 准备公开分享

应用可准备分享包，并通过 GitHub 工作流创建 PR 与分享码。先预览包内容，检查个人路径、凭据和 Provider State，确认后提交并查看公开结果。

在独立目录验证路径匹配、草稿创建、备份和还原。分享文件提供策略；换电脑恢复现有版本时，按[数据迁移](/docs/guides/data-migration)准备配置、历史与归档。

相关操作见[模板管理](/docs/guides/templates)。
