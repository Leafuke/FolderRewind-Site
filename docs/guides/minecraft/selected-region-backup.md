# Minecraft 指定区域备份

只想保留建筑附近的世界内容时，可以设置矩形区域。MineRewind 按方块坐标选择所涉及的区域文件，并生成部分备份。

## 选择范围

从[地图工作区](/docs/guides/minecraft/world-preview)选择区域，或在备份策略中选择插件范围，指定主世界、下界或末地，再每行输入 `x1,z1,x2,z2`：

```text
-512,-512,512,512
0,0,511,511
```

坐标使用方块位置。区域文件索引为 `floor(block/512)`，例如 -0.5 对应 -1，511 对应 0，512 对应 1。两个角可以交换，选择会扩展到涉及的区域文件边界。

## 检查输入

| 项目 | 范围 |
| --- | --- |
| areas 文本 | UTF-8 最多 32 KiB |
| 矩形 | 最多 128 个有效行，空行和 `#` 注释跳过 |
| 坐标 | 有限数值，位于 -30000000 到 30000000 |
| 区域文件 | 每维度最多 4096 个去重区域 |
| 每行格式 | 四个逗号分隔的数值 |

保存前根据诊断修正空范围、非法坐标或歧义维度。来源范围和项目过滤还会继续收窄，查看有效文件预览确认实际内容。

## 包含哪些文件

所选区域纳入各维度 `region`、`entities`、`poi` 中对应的 `.mca`，以及必要世界、玩家和数据文件。外置大区块数据会包含相关维度目录的全部 `c.*.*.mcc`，因此实际大小可能超过矩形估计。

支持识别的 Vanilla、Paper/Spigot 和新版维度布局。Paper/Spigot 同级维度需要把包含它们的服务器根目录作为来源，再确认维度路径。

## 还原与检查

区域备份使用 Overwrite，还原捕获的内容并保留其他当前区域。先关闭游戏或完成热协调，在副本中检查各维度、实体、POI 和大区块，再继续使用。

区域能力面向 Java 世界。Bedrock 世界关闭游戏后使用完整普通文件备份。需要合并分支成果时，阅读[世界合并](/docs/guides/minecraft/world-merge)。
