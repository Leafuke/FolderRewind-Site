# Minecraft 指定区域备份

FolderRewind 1.8 可以只备份 Minecraft 存档中指定范围内的区域文件。它适合超大型世界的分区保护，但产生的是**部分备份**，不能当作完整世界快照使用。

:::danger 部分备份只能覆写还原
无论普通还原还是热还原，指定区域备份都会强制使用 **Overwrite（覆写）**。不能选择 **Clean（清空后还原）**，否则未包含在备份中的世界文件可能被删除。
:::

## 配置入口

1. 打开 Minecraft 存档对应配置的 **配置设置**。
2. 进入 **备份策略**，将备份范围设为 **Minecraft 指定区域**。
3. 选择需要保护的维度。
4. 每行填写一个区域范围，格式为 `x1,z1,x2,z2`。
5. 保存后先执行一次手动备份，并在测试副本中验证内容。

例如：

```text
# 出生点附近的矩形范围
-2,-2,2,2

# 第二个范围
10,8,14,12
```

这里的坐标是 `.mca` **区域文件坐标**，不是方块坐标或区块坐标。两个角的顺序不影响矩形范围。

## 维度与目录布局

可以分别为主世界、下界和末地选择范围。FolderRewind 会识别受支持的世界布局，包括：

| 维度 | 常见目录示例 |
|------|--------------|
| 主世界 | `region/`、`entities/`、`poi/` |
| 下界 | `DIM-1/region/`，以及 Paper/Spigot 等对应的世界目录 |
| 末地 | `DIM1/region/`，以及 Paper/Spigot 等对应的世界目录 |

识别范围覆盖传统 Vanilla 布局、Paper/Spigot 的分维度布局，以及 Minecraft 26.1 及更新版本采用的受支持布局。若目录同时匹配多个有歧义的布局，备份会被拒绝，而不会猜测。

每个入选区域会包含对应的 `region`、`entities` 和 `poi` 中的 `.mca` 文件，以及它们引用的外部 `.mcc` 文件。FolderRewind 还会保留完成有效还原所需的必要世界文件。

## 输入限制

| 项目 | 限制 |
|------|------|
| 配置文本大小 | 最大 32 KiB |
| 有效范围行数 | 每个配置最多 128 行（空行和注释不计） |
| 坐标范围 | `-30000000` 到 `30000000` |
| 去重后的区域文件 | 每个维度最多 4096 个 |
| 行格式 | 严格使用 `x1,z1,x2,z2`，四项都必须是整数 |

可以使用以 `#` 开头的注释行。越界坐标、缺少字段、额外字段、非整数或展开后超过限制都会使**整个备份**失败；FolderRewind 不会偷偷跳过错误行后生成不完整结果。

## 与过滤器的关系

指定区域模式会用计算出的区域范围替代普通备份白名单。不要依赖常规白名单继续扩大备份范围；区域选择才是本次备份的范围事实来源。

配置中的排除规则仍应谨慎使用。修改过滤器或区域范围后，请重新检查备份内容并执行还原测试。

## 安全还原规则

- 普通还原和热还原都强制采用 **Overwrite**。
- **Clean** 不可用，未备份的区域和其他文件不会先被清空。
- 覆写只恢复包内内容，不代表目标世界的其他区域会回到同一时间点。
- 还原前应停止服务器写入；热还原则必须遵循 MineRewind 的存档卸载和重新加载流程。
- 第一次用于生产数据前，先复制世界并验证维度、实体、POI 与外部区块文件。

## 备份被拒绝时

依次检查：

1. 每行是否严格符合 `x1,z1,x2,z2`。
2. 坐标、行数、文本大小和去重区域数是否在限制内。
3. 所选维度是否存在，世界布局是否受支持且无歧义。
4. 存档目录是否完整，进程账户是否有读取权限。

不要通过删减错误提示中提到的必要目录来强行通过校验。指定区域模式采用失败关闭策略，拒绝备份通常表示无法保证结果可安全还原。
