# 世界地图、历史预览与对比

想看旧建筑的位置、比较两次备份间的变化，或挑选需要保护的区域，可以直接打开 MineRewind 的世界地图。

![在地图工作区对比世界版本，查看区块变化。](/img/docs/v1-10-0/map-compare-110-zh-light-1604.webp)

## 打开当前世界或历史备份

启用 MineRewind，添加有效的 Java 世界来源。从管理页的来源操作菜单打开地图预览；在历史中选择本地可准备的世界版本，也可以进入历史地图与版本对比。

历史预览会先将所需备份和依赖准备到临时目录，再读取世界内容。加密版本需要密码，插件表示需要对应物化能力。地图浏览按只读方式进行。

## 浏览与定位

- 切换世界和维度，拖动、缩放地图，查看已生成地形。
- 从导航目标选择玩家或保存的位置，也可以输入坐标定位。
- 使用地表、洞穴或指定高度切片视图，按维度调整高度。
- 选择区块查看详情，结合状态图例区分已读取、正在处理、未生成或格式受限的区域。

地图会逐步读取可见区域，远景先显示概览。需要看细节时，放大到目标位置并等待读取完成；当前世界变化后使用刷新重新读取。

## 比较两个版本

选择左右两侧版本，检查世界、维度和时间。按变更类别筛选新增、删除、修改等区块变化，再在地图与变更列表中定位具体位置。

部分备份的可见内容取决于实际捕获范围。查看状态和覆盖提示，再判断某一区域在所选版本中的变化。需要把两个分支的成果组合起来时，进入[世界合并](/docs/guides/minecraft/world-merge)。

## 从地图选择备份区域

在支持区域选择的地图工作区中框选范围，检查世界、维度和有效范围，再将选择用于备份范围设置。区域会转换成插件的选区参数，由项目设置保存；详细规则见[指定区域备份](/docs/guides/minecraft/selected-region-backup)。

## 无法加载时

检查世界路径、MineRewind 运行状态和所选历史的本地依赖。切换到已有生成数据的维度，按区块详情中的格式或读取诊断处理。Java 地图支持由插件提供，Bedrock 存档按普通文件夹流程备份。

开发者可查看[空间预览与对比契约](/docs/plugins/developing/plugin-api#spatial-preview)。
