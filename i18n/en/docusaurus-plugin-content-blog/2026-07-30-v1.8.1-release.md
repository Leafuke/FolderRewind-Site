## FolderRewind v1.8.1

FolderRewind 1.8.1 is an emergency hotfix for the 1.8.0 startup failure.

<!-- truncate -->

:::tip Download advice
Prefer [Microsoft Store](https://apps.microsoft.com/detail/9nwsdgxdqws4). Do not install Store, MSI, and MSIX builds together.
:::

## What's changed

- Fixed a pre-window startup exit when an existing configuration contained zh_CN or en_US.
- Migrated legacy language values to zh-CN or en-US; unknown values safely fall back to the system language.
- If Windows rejects the language override, the app falls back to the system language and continues starting.

## If 1.8.0 cannot start

1. Close FolderRewind and back up config.json first.
2. Change only GlobalSettings.Language to system, zh-CN, or en-US.
3. Save, restart, and confirm that the UI and configuration load normally.
4. Do not delete the entire config file; keep the backup and logs if the issue continues.

Store/MSIX config path:

~~~text
%LOCALAPPDATA%\\Packages\\<PackageFamilyName>\\LocalState\\FolderRewind\\config.json
~~~

MSI config path:

~~~text
%LOCALAPPDATA%\\FolderRewind\\config.json
~~~

## Upgrade guide

Back up configuration, history, and plugins before switching channels. Store/MSIX and MSI use different locations and do not migrate these assets automatically. See [1.8 Upgrade and Recovery](/en/docs/getting-started/v1-8-upgrade) for Template Envelope and KnotLink compatibility notes.
