## FolderRewind v1.7.2

v1.7.2 is a transition release toward the 1.8 remote-integration model. It experimentally introduces parameterized remote commands and fixes a few minor issues. v1.7.3 was not published separately on GitHub.

<!-- truncate -->

:::warning Compatibility note
This is a transition release, not the final 1.8 parameterized-protocol contract. Keep the current config and plugins, and prepare integration callers with the 1.8 guide before upgrading further.
:::

## Update content

- Experimentally introduced parameterized remote commands as groundwork for stronger mod integrations.
- Fixed several minor issues.
- 1.7.3 was not released separately on GitHub.

## Upgrade guide

Most users can continue with Microsoft Store. KnotLink or Minecraft integration users should record current commands and plugin versions, and validate in a test configuration. The 1.8 migration requires strict key-value parameterized protocol v2 together with KnotLink Server v3.
