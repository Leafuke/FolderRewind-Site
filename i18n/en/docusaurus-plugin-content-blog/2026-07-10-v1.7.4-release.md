## FolderRewind v1.7.4

This minor release is also a special interim hotfix: it maintains older protocol compatibility while fixing serious issues and selectively shipping features originally planned for 1.8.0.

<!-- truncate -->

:::warning Experimental features
Selected-area backup, performance presets, and folder rename/refactor had not received long-term validation in this release and were not recommended for production data. Validate backup and restore in a test directory first.
:::

## Update content

1. Fixed folder-selection crashes on some devices ([#32](https://github.com/Leafuke/FolderRewind/issues/32) [@UMP40](https://github.com/UMP40), [#36](https://github.com/Leafuke/FolderRewind/issues/36) [@xuanluomia](https://github.com/xuanluomia)).
2. Fixed strict validation being skipped in special environments during automatic backup and other paths ([#38](https://github.com/Leafuke/FolderRewind/issues/38)).
3. Fixed multiple page display issues.
4. Improved page loading, startup speed, and network connection stability.
5. Refined multiple text prompts.
6. Added custom advanced backup parameters ([#33](https://github.com/Leafuke/FolderRewind/issues/33) [@Scriptbeta](https://github.com/Scriptbeta)).
7. Improved multilingual support.
8. Included multiple performance improvements.
9. Selectively introduced 1.8.0 features; see the 1.8.0 release notes for the complete list.

## Compatibility

This was expected to be the last release using the legacy interconnection system. Data structures remained compatible with 1.7.3 and earlier, but some plugins needed updates.

## Upgrade guide

Verify folder selection and automatic-backup validation first, then test advanced 7-Zip parameters separately. Treat region scope, performance presets, and rename as experimental; do not enable them for production worlds without a rollback copy.
