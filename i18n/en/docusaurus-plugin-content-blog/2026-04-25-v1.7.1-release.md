## FolderRewind v1.7.1

This minor release focuses on cloud archive retrieval, history synchronization, and template usability.

<!-- truncate -->

:::tip Download advice
Continue to prefer [Microsoft Store](https://apps.microsoft.com/detail/9nwsdgxdqws4). Do not install Store, MSI, and MSIX sideloaded builds together.
:::

## Update content

1. Added on-demand cloud download for restore.
2. Added direct history synchronization from the History page.
3. Added template rule marker files.
4. Added a Minecraft Starter Preset in plugin settings for installing several extensions in one step.
5. Improved multiple prompt texts.
6. Refined interface layout.

## Upgrade guide

If rclone cloud archive is already configured, download and restore one history item after upgrading before re-enabling automatic cloud retrieval. Template authors should recheck marker-file rules. Minecraft users can use the starter preset, but should still verify plugin versions and backup targets.
