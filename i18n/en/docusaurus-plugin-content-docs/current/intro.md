# Quick start

FolderRewind keeps backup versions of important folders on Windows. Save a project's progress, schedule regular backups, or recover files that you changed or deleted by mistake.

![Organize folders by project and access favorite sources quickly.](/img/docs/v1-9-6/home-en-light-1604.webp)

*Organize folders by project and access favorite sources quickly. Interface version: 1.9.6.*

## Start with one folder

1. [Install the app](/docs/getting-started/installation). Choose Microsoft Store or a Setup EXE for your device.
2. [Create your first backup](/docs/getting-started/first-backup). Add a folder, choose a separate backup location and save a full version.
3. [Try a restore](/docs/getting-started/first-restore). Verify the result with test files before enabling automatic backups.

## Current versions

These guides are reviewed against **FolderRewind 1.9.6**, which bundles **MineRewind 1.9.8** and supports **Plugin API 3.9**. The separate public plugin release is still **1.9.5**; NuGet examples use **SDK 3.6.0**. Store and GitHub updates may arrive at different times. Check the installed version in About.

The [original MineBackup guides](/docs/guides/minebackup-v1/overview) cover a separate product with its own configuration, CLI and backup modes.
