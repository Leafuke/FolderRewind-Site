# Quick start

![Empty-config home; isolated FolderRewind1.9.2.0/API3.5 candidate, Chinese UI](/img/docs/v1-9/home-candidate.png)

*Empty-config home; isolated FolderRewind1.9.2.0/API3.5 candidate, Chinese UI.*


FolderRewind is a WinUI3 Windows backup manager.1.9 adds native immutable history, Full/Smart/Rolling, cloud replicas, game discovery and Plugin System v3. These docs use an API3.5 candidate baseline; verify actual availability at download entrypoints.

## Verify in three steps

1. Choose Store/Setup using [installation](/docs/getting-started/installation); existing users read [1.9 upgrade](/docs/getting-started/v1-9-upgrade).
2. Create a test config, inspect managed scope/separate destination and make a [first backup](/docs/getting-started/first-backup).
3. [Restore test copies](/docs/getting-started/first-restore), checking adds/edits/deletions and real application loading before automation.

## By scenario

- Files: [modes](/docs/guides/backup-modes), [filters](/docs/guides/filters), [automation](/docs/guides/automation).
- Games: [discovery Beta](/docs/guides/game-discovery), [Minecraft](/docs/guides/minecraft/overview).
- History: [views](/docs/guides/history-timeline), [branches/merge](/docs/guides/history-branches), [safety points](/docs/guides/safety-snapshots).
- Cloud/transfer: [cloud](/docs/guides/cloud-archive), [migration](/docs/guides/data-migration).
- Developers: [standalone SDK](/docs/plugins/developing/quick-start), [API](/docs/plugins/developing/plugin-api).

Logical records, materializable representations and actual bytes differ. Success/cloud icons/Enabled switches do not replace restore verification. MineBackup has [independent docs](/docs/guides/minebackup-v1/overview); its CLI/formats are not FolderRewind contracts.
