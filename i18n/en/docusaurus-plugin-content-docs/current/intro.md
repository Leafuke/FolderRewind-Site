# Quick start

FolderRewind saves versions of important folders on Windows. Make a backup before working, recover an earlier file after an accidental edit, or let the app regularly save your projects and game worlds in the background.

![Organize folders by project and start backups from frequently used sources.](/img/docs/v1-9-6/home-en-light-1604.webp)

## Start with one folder

1. [Install the app](/docs/getting-started/installation) from Microsoft Store or choose the Setup package for your device.
2. [Create your first backup](/docs/getting-started/first-backup): add a folder, select backup storage and save a complete version.
3. [Try a restore](/docs/getting-started/first-restore) with a few test files to learn how to recover content.
